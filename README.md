### 🚀 Qué hago

Desarrollador full-stack con preferencia por el **backend, la arquitectura de sistemas y el desarrollo móvil nativo**. Diseño e implemento software de producción de punta a punta: desde microservicios y APIs hasta aplicaciones Android nativas y plataformas web modernas.

- 🏗️ **Backend & Arquitectura** — Microservicios en **.NET**, APIs con **Node.js/TypeScript**, diseño multi-tenant y bases de datos relacionales.
- 📱 **Android Nativo** — Apps con **Kotlin** y **Jetpack Compose**, arquitectura **MVVM** (Vista → ViewModel → UseCase → Repository → DAO), enfoque offline-first.
- 🌐 **Web moderna** — **Next.js**, **React**, **TypeScript** y **Supabase** para productos rápidos y escalables.
- ☁️ **Infra & DevOps** — Despliegues en **Kubernetes**, **Vercel** y **Cloudflare**; integraciones y automatización.
- 🧾 **Dominio de negocio** — Integraciones de facturación electrónica, impresoras fiscales y sistemas POS.

### 💼 Freelance — devpalmar
